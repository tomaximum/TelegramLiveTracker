Liaison des groupes (Via Telegram) :

Pour lier vos deux groupes au Live Tracker, ajoutez le Bot comme membre et administrateur dans chacun des groupes, puis envoyez les commandes suivantes :

  • Dans le groupe Administration/Télémétrie : /setup admin
  • Dans le groupe Participants (Chat & Cartographie) : /setup chat
